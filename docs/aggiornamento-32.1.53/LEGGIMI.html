Guida completa passo dopo passo · Elenco dei file · Prove e limiti

01 · Esegui prima la migrazione SQL

  1. Apri Supabase e seleziona il progetto già usato dalla Sisal.
  2. Apri SQL Editor → New query.
  3. Apri sul PC SQL/20-gazzetta-automatica.sql, copia tutto e incolla nella query.
  4. Premi Run e attendi Success. Se compare l’avviso RLS, scegli Run and enable RLS: il file abilita già RLS sulla nuova tabella.

Nessun account, foto, comunicato o JSON viene cancellato. Non occorrono chiavi o password nuove.

02 · Carica ed elimina in un solo commit

  1. Apri il repository nell’editor web. Controlla il branch main.
  2. Apri Explorer a sinistra e trascina il contenuto di 01_FILE_GITHUB nella radice del repository. Accetta le sostituzioni.
  3. Elimina i file elencati sotto. Puoi selezionare gruppi con Ctrl/Shift. Non eliminare file diversi.
  4. Apri Source Control, includi tutte le modifiche con il + accanto a Changes e scrivi il messaggio Sisal 32.1.53: rimozione Arena e Gazzetta automatica.
  5. Premi Commit & Push per pubblicare su main.

Repository GitHub · Caricamento classico alternativo

Le istruzioni dettagliate per selezionare i gruppi da eliminare sono in INSTALLAZIONE.md. Non caricare il backup, i log o lo ZIP.

03 · Attendi Ready su Vercel

  1. Apri Deployments della Sisal.
  2. Attendi Ready per il nuovo commit main in Production.
  3. Apri la web app, ricarica e verifica v32.1.53 in fondo.

Termux mantiene gli stessi pulsanti e la chiave personale. Le variabili Vercel già usate dall’app restano valide.

04 · Controlla il risultato

  1. Clic sul logo: nessuna finestra.
  2. Squadra → Gazzetta: ultima partita con risultato, titolo e rubriche. La prima volta puoi premere Prepara / riprova edizione per convertire subito l’edizione precedente.
  3. Con nuovi JSON della tua squadra, la redazione parte dopo circa 20 secondi di quiete. File identici: nessuna nuova generazione. L’avversario non genera il giornale.
  4. Un membro vede e condivide la prima pagina, ma non ha comandi di preparazione o controllo. La Gazzetta non compare in Fun.
  5. Prova menu, foto personali, una gara e condivisione dal telefono reale.

Se Gemini non risponde o esaurisce la quota, resta l’ultima edizione valida. Il tentativo manuale di un amministratore serve anche a recuperare un lavoro interrotto dalla piattaforma.
